# Try it

A public demo network runs Companies, so you can try it before installing it.

- **Server:** `demo.companies.eldoria.de` with Minecraft Java Edition 26.3
- **Dashboard:** [demo-companies.eldoria.de](https://demo-companies.eldoria.de)

You land on `hub`, where companies, orders and weeks of market prices are already waiting. Run `/company dashboard`
and open the link with the code it shows: the demo dashboard is the quickest way around. Browse the order book and the
market, join Stonebridge, Copperworks or Greenfield Farms in game with `/company join <name>`, take orders, place
your own and deliver items. `/demo guide` gives you the guide book again. `/server lands` takes you to
the second node, with land claims and plots, and `/server hub` back to spawn.

`/demo admin` makes you an admin for 30 minutes, so you can try the admin tools in game and on the dashboard, after
logging in to it again. The tools that could create money, take other visitors' land or change the server's setup stay
locked: grants, treasury changes, renames, deleting companies and reloading or editing the configuration.

The demo resets every night: everything you built, earned or ordered is gone the next day.
